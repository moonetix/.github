# Getting help

GitHub issues are for bugs in the code of these repositories. Most other questions get a faster answer elsewhere.

## Integration questions

Signing the offerwall link, postback macros, a hash that does not match, how reversals work:

1. [docs.moonetix.com](https://docs.moonetix.com) is the reference. Start with [Offerwall link](https://docs.moonetix.com/offerwall-link), [Postbacks](https://docs.moonetix.com/postbacks) and [Testing](https://docs.moonetix.com/testing).
2. [Moonetix Academy](https://moonetix.com/academy) has step by step guides for each stack, from Next.js to Unity.
3. Two free tools find most problems in a minute: the [offerwall link builder](https://moonetix.com/tools/offerwall-link-builder) and the [postback hash checker](https://moonetix.com/tools/postback-hash-checker).
4. Still stuck? Write to us through [moonetix.com/contact](https://moonetix.com/contact). Include your app ID, your postback URL template, one example postback and what your server answered. Never send your link hash salt or postback secret key.

## Account, offers and payouts

Questions about your account, an offer, a missing reward or a payout are not code questions. Use [moonetix.com/contact](https://moonetix.com/contact).

## Bugs in this code

If code from one of these repositories does something different from what its README or the docs say, open an issue in that repository with the **Bug report** form. Include the version and a way to reproduce it.

## Security problems

Report them privately. See [SECURITY.md](SECURITY.md).
